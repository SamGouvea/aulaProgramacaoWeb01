— ONG Juntos Pelo Bem

🏷️ Projeto
ONG Juntos Pelo Bem é uma aplicação web responsiva que apresenta os projetos sociais da organização, permite o cadastro de voluntários e implementa um sistema básico de SPA (Single Page Application) para navegação fluida entre páginas.

🚀 Funcionalidades
✅ Navegação SPA sem recarregamento de página

✅ Cadastro de voluntários com validação de dados

✅ Armazenamento local dos cadastros via localStorage

✅ Exibição dinâmica de voluntários cadastrados

✅ Menu mobile com toggle responsivo

✅ Animações suaves ao scroll

✅ Máscara de telefone no formulário

📦 Como Executar Localmente
Clone o repositório:
git clone https://github.com/SamGouvea/aulaProgramacaoWeb01.git

Acesse a pasta do projeto:
cd aulaProgramacaoWeb01

Inicie um servidor local (recomendado):
Com Live Server (VS Code)
Ou com Python:
python -m http.server

Acesse no navegador:
'http://localhost:8000'

📋 Observações
O SPA funciona apenas quando o projeto é servido por um servidor local — abrir os arquivos diretamente (file://) pode impedir o funcionamento do fetch.

Os dados de voluntários são armazenados localmente e não são enviados para nenhum servidor externo.

O projeto é totalmente client-side e não requer backend.
